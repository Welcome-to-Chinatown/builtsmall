What to do with it

  1. Open Gemini, ChatGPT, or Claude.
  2. Start a new chat and attach your CSV (the paperclip button).
  3. Use the four-part prompt from the session. Tell it: “Build an interactive dashboard as an HTML artifact I can open in my browser — charts and totals, not a spreadsheet.”
  4. Open what it builds. Change one thing, run it again.

Sample data only. Never upload real customer, client, or financial records into a public AI tool.
