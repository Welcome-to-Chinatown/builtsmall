The one idea

What a markdown (.md) file is

A markdown file is a plain-text instruction sheet — just words, no formatting menus. The .md on the end is all that makes it special.

When you build software with an AI coding tool, that tool reads one special .md file first, every time, to understand your project. It's the project's brain:

  • CLAUDE.md — for Claude Code
  • AGENTS.md — for Codex, Cursor, Copilot, and most others
  • GEMINI.md — for Gemini

You don't write it by hand. You get an AI to write it for you — that's step 3 below. Think of it as the four-part prompt from this morning, saved to a file so your coding tool never forgets it.

Step 1 · your project folder

Set up the folder

  2. Download one of the sample datasets and drop it inside.
⇩ Get your data Worked when you open my-dashboard and see your .csv inside. (We'll use the cafe file below; any works.)
Step 2 · write your md file · 5 minutes

Have an AI write your .md

  1. Open a regular AI chat (not the coding tab). Attach your CSV with the paperclip.
  2. Paste the prompt below. Your only job: edit the Features list — keep what you want, cut the rest, add your own.
  3. It replies with the file in one code block. Save it as CLAUDE.md (or AGENTS.md for Codex / GEMINI.md for Gemini) in your my-dashboard folder.
Prompt · paste into an AI chat, attach the CSV 
I need a CLAUDE.md file (or AGENTS.md / GEMINI.md) for a new project.

Project: Finance Dashboard
Purpose: A dashboard for a small organization. I upload my data (CSV, attached) and it shows my key numbers and charts at a glance.
Tech stack: Next.js, React, Chart.js, no database. Everything runs in the browser. No login. Nothing is stored.
Rules: Must run locally and be ready to publish on Vercel. Use the latest versions.

Features:
- Upload a CSV file (my sample file is attached)
- Auto-clean messy data (mixed dates, inconsistent category names, blanks)
- Summary cards for the totals that matter
- A bar chart and a line chart
- A table of the top items
- A couple of filters (for example by category or date)
- Use a navy and cream color scheme

Keep it 40-60 lines. Confirm it covers every feature when done.
If your data is...Good summary cardsGood charts
Cafe salestotal revenue, orders, best sellerrevenue by category, by day
Nonprofit budgetfunding in, spending, net, by programspending by program, funding by source
Services billingtotal billed, unpaid, by clienthours by service, revenue by client
Saving as .md: easiest is to ask your coding agent to create the file and paste the text. Or a plain-text editor — TextEdit: Format → Make Plain Text, save as .md not .txt.Notepad: "Save as type" → All Files, name it CLAUDE.md.
Step 3 · build it · about 20 minutes

Hand it to your coding agent

  1. Open your coding tool and choose your my-dashboard folder. In Claude: Code tab → Local → the folder → a mode that accepts edits.
  2. Paste this and press Enter. It may ask to run commands — say yes.
Coding agent · build 
Build the dashboard described in my CLAUDE.md / AGENTS.md / GEMINI.md file. Use the latest Next.js. This folder already has my md file and sample CSV, so do not overwrite them. Ask me any questions first. When ready, run it locally so I can open it at localhost:3000.
  1. Open it. Type localhost:3000 in any browser. It only exists on your computer.
  2. Test it. Upload your CSV. The cafe file should total about $18,600 revenue across 100 rows (nonprofit: ~$347K funding in; services: ~$55.8K billed).
Good signs: messy category names group into one, and the filters change the numbers. If anything looks off, tell your agent what you see in plain words.

Step 5 · ship it

GitHub, then Vercel

GitHub stores your code and every past version. Your agent does it for you:

Coding agent · GitHub 
Create a new private GitHub repository called my-dashboard under my GitHub account and push this project. Make sure my commits use my GitHub account's email. Make sure node_modules is not uploaded.

Vercel turns that code into a real website — all clicks, in the browser:

  1. Go to vercel.com/new, sign in with GitHub.
  2. Find my-dashboard, click Import. Not listed? Adjust GitHub permissions to allow it, come back.
  3. Leave every setting as-is (it should detect Next.js). Click Deploy, wait ~1 minute.
  4. Copy your short link — the one like something.vercel.app.
Worked when the short link opens in a private window or on your phone, no login. It's live.

Your agent commits and pushes; Vercel rebuilds in about a minute; refresh your live link and your change is on the internet.

Nothing new in Vercel after two minutes? Your git email probably doesn't match your GitHub email. Ask your agent: Check my git email against my GitHub account, fix it, and push again.
Three honest things

Before you share it

It's public

Anyone with the link can open it. Never upload real customer or financial data.

Free is for practice

Vercel's free plan is non-commercial. For a real business site, use a paid plan or another host.

Nothing is stored

Each visitor uploads a file; it stays in their browser. The site keeps nothing.

Hit an error? Don't retype it — copy the exact message, paste it to your agent, and ask it to fix it. That's the whole loop.
