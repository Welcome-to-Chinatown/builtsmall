TRY IT Practice: the finance dashboard ›

A home-goods shop has 100 orders in a messy spreadsheet (mixed date styles, mismatched category names, refunds). Your job is to write the prompt that turns it into a clear dashboard. Works in any AI chat tool that can read a file (ChatGPT, Claude, Gemini).

  1. Download the data: retail_store_data.csv — 100 sample orders, messy on purpose (not a real business).
  2. Start a new chat, attach that file, then paste this prompt and write your own Steps (the Role and Output are done; you fill in the numbered steps):
Role & goal: You are my business analyst. I run [type of shop] and I want a dashboard that shows how my shop is doing.

Steps: (write the steps you want it to follow — what to clean, what to add up, what to show)
1. ______
2. ______
3. ______

Output: A simple dashboard with number cards, a bar chart, a line chart, and a table. Plain English labels, no jargon.
Eval: Before you answer, check your totals against the file and tell me which cleaning choices you made.

Check your numbers: revenue about $3,825, 100 orders, average order about $38, refunds $321.52, 6 categories after merging. Stuck on the steps? The finance dashboard handout has a full version.

YOUR TURN Practice: your own PITA prompt ›

Now write a prompt for your own business. PITA is the recipe: Persona (who the AI is), Instructions (the steps), Task (what you want back), Ask for a check. Use the canvas to draft it.

  1. Open the canvas: PITA prompt canvas. Fill in each box for a real task you do.
  2. Paste what you wrote into a new chat. Attach a file if the task needs one.
  3. Read the result, then fix one thing in your prompt and run it again.

Good sign: the second run is noticeably closer to what you actually wanted.

KEEP IT Save your prompt as a project ›

A prompt you like is worth keeping. Every major tool lets you save a prompt and a file as a reusable "project" so you do not start from scratch next time.

  1. Claude: make a Project, paste your prompt into the project instructions, and add your file as project knowledge.
  2. ChatGPT: make a Project (or a custom GPT), set the instructions to your prompt, and attach your file.
  3. Gemini: make a Gem, put your prompt in the instructions, and upload your file.

Why it matters: next month, you open the project, drop in a fresh spreadsheet, and the dashboard builds itself — same prompt, new data.
